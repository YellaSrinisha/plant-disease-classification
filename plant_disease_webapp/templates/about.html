🔬 Project Overview

This web application uses a classical machine learning ensemble to detect plant diseases from leaf photographs. It was built as part of an academic project to demonstrate that lightweight, interpretable models can achieve high accuracy without deep learning.

The system targets the lab-to-field performance gap — the drop in accuracy when models trained on clean lab images encounter real farm photos. Mixed-dataset training, field-aware preprocessing, and ensemble voting help bridge this gap.

⚙️ Methodology (v2 — field-robust)

  • Preprocessing: Resize (224×224) → Gray-World colour constancy + per-channel percentile stretch → CLAHE illumination normalisation (L* channel, clip=2.5) → 3-strategy leaf segmentation cascade (ExG+HSV Saturation → HSV green-range → centre-bias Gaussian; falls back to full image if all strategies fail, preventing corrupt frames)
  • Training augmentation: 5 augmented copies per training image — random combinations of rotation, crop/zoom, perspective warp, flips, brightness/contrast, shadow strips, hue/saturation shifts, JPEG compression, motion blur, and Gaussian noise. Augmentation is applied to the training split only.
  • PlantDoc upweighting: Each PlantDoc (field) training sample is given 3× the weight of a PlantVillage sample during SVM and RF training, directly addressing the lab-to-field class imbalance.
  • Features: 66-dimensional vector — 20 colour (RGB/HSV channel stats + vegetation indices: G/R, G/B, NDI, ExG), 30 texture (GLCM contrast/correlation/energy/homogeneity over 4 angles + 26-bin LBP histogram on foreground pixels), 16 shape (normalised area & perimeter, compactness, eccentricity, aspect ratio, solidity, 7 log-scaled Hu moments, lesion count / density / area ratio)
  • Classifiers: KNN (distance-weighted, grid search over n_neighbors and metric), SVM (RBF kernel, CalibratedClassifierCV for probabilities, balanced class weights, grid search over C and gamma), Random Forest (balanced class weights, grid search over n_estimators, max_depth, min_samples_leaf, max_features). All use 5-fold stratified GridSearchCV scored by macro F1.
  • Ensemble: Weighted soft voting — each model's weight equals its validation accuracy; probability columns are aligned across models so differing class subsets are handled safely.

📁 Datasets

Models were trained on a subset of two public datasets. The counts below reflect images actually included in this project.

  • PlantVillage — 5,000 lab-quality images (1,000 per class)
  • PlantDoc — 447 real field images (68–117 per class)
  • Total: 5,447 images across 5 classes

Original PlantVillage: ~54,306 images (38 classes). Original PlantDoc: ~2,598 images (27 classes). This project uses a 5-class subset.

⚠️ Limitations

  • Designed for single-leaf close-up photos — not whole plant or fruit images
  • Only classifies the 5 trained disease classes
  • Classical features may not capture fine-grained patterns that deep CNN features learn
  • Field (PlantDoc) accuracy is lower than lab accuracy due to distribution shift
  • Gray-World colour constancy can fail on images with a dominant single colour

🛠️ Technology Stack

  • Backend: Flask (Python)
  • ML: scikit-learn, OpenCV, scikit-image
  • Frontend: Vanilla HTML, CSS, JavaScript
  • No deep learning — purely classical ML
